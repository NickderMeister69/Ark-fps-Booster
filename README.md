# ARK FPS Booster

Windows-App mit grafischer Oberfläche, die mehr FPS aus **ARK: Survival Evolved** und **ARK: Survival Ascended** holt – mit einem Klick.

## Starten

1. Repository herunterladen (Code → Download ZIP) und entpacken.
2. Doppelklick auf `ARK FPS Booster starten.bat`.
3. Die Admin-Abfrage mit „Ja“ bestätigen.
4. Profil wählen (Sicher / Empfohlen / Maximum) → **1-KLICK BOOST**.

## Funktionen

- Live-Monitor: CPU, RAM, GPU-Last, GPU-Temperatur, Grafikspeicher (NVIDIA), ARK-Status
- Profile, gespeicherte Auswahl, Auto-Boost beim ARK-Start
- Windows-Tweaks: Energieplan, Spielmodus, Game Bar aus, Scheduler-Priorität, Netzwerk-Drosselung, Mausbeschleunigung, Benachrichtigungen, Hintergrund-Apps, Power Throttling, Einrastfunktion-Popup, Transparenz, GPU-Planung
- ARK-Tweaks: Vollbildoptimierung, GPU-Präferenz, CPU-Priorität, Grafik-Configs (Preset, FPS-Limit, Auflösung, V-Sync, Effekte), Intro-Videos überspringen (ASE)
- Aufräumen: Temp-Dateien, RAM, Shader-Cache, DNS-Cache
- Hintergrundprogramme erkennen und schließen, Ping-Test, Systeminfo
- **Alles rückgängig machen**: Jede Änderung wird vorher gesichert (`%APPDATA%\ArkFpsBooster`)

## Voraussetzungen

Windows 10/11, Windows PowerShell 5.1 (vorinstalliert). Keine weiteren Installationen nötig.
